Approval Rules

Configure approval workflows for expense management

Basic Information

This approval rule applies to all expense reports submitted by Marc Johnson that exceed $500 in value.

Manager Approval

When enabled, approval requests will first be sent to the employee's manager before proceeding to other approvers.

Required approvers must approve the request for it to proceed. If a required approver rejects the request, the expense is automatically rejected.

Approval Workflow

When enabled, approvers will receive requests in sequence (John → Mitchell → Andreas). When disabled, all approvers receive requests simultaneously.

Approval Threshold
%

The percentage of approvers who must approve the request for it to be approved. Set to 0% if any single approval is sufficient.
